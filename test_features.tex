\section{테스트 1: Smart Backspace (구조 통째로 삭제)}
아래의 명령어들에서 커서를 백슬래시(\textbackslash) 바로 앞에 두고 백스페이스를 눌러보세요.

1. 비어있는 분수: \frac{}{}  % <-- 여기서 \에 커서 두고 Backspace
2. 비어있는 제곱근: \sqrt{}   % <-- 여기서 \에 커서 두고 Backspace
3. 비어있는 합계 기호: \sum_{}^{} % <-- 여기서 \에 커서 두고 Backspace
4. 인자가 있는 경우 (삭제되지 않아야 함): \frac{1}{2} % <-- 여기서 \에 커서 두고 Backspace 시 일반 동작 수행

\section{테스트 2: Math Mode Toggle (수식 모드 전환)}
아래의 각 수식 내부(어디든 상관 없음)에 커서를 두고 \textbf{Ctrl+Alt+M} (macOS: \textbf{Cmd+Alt+M})을 눌러보세요.
순서: $ ... $ $\rightarrow$ \[ ... \] $\rightarrow$ \begin{equation} ... \end{equation} $\rightarrow$ $ ... $

1. 인라인 수식 테스트: $E = mc^2$

2. 디스플레이 수식 테스트:
\[
    a^2 + b^2 = c^2
\]

3. Equation 환경 테스트:
\begin{equation}
    \int_{0}^{\infty} e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
\end{equation}
