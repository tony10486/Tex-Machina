\section*{Semantic Math Refactor Test Cases}

이 파일은 `Semantic Math Refactor` 기능을 다양한 상황에서 테스트하기 위해 작성되었습니다.
각 섹션에서 변수 \textbf{x}를 \textbf{\theta}로, 또는 \textbf{\alpha}를 \textbf{\gamma}로 변경하며 결과를 확인해 보세요.

\subsection{1. 기초적인 상황 (Simple Cases)}
\begin{itemize}
    \item 인라인 수식: $x + y = z$
    \item 거듭제곱 및 첨자: $x^2 + x_i = x_{n+1}$
    \item 디스플레이 수식:
    \[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]
\end{itemize}

\subsection{2. 명령어 보호 (Command Protection)}
수식 명령어의 일부인 'x'는 변경되지 않아야 합니다.
\begin{itemize}
    \item 명령어 내부의 x: $\max(x) + \exp(x) + \ln(x)$
    \item 텍스트 모드 보호: $x + \text{this is x} + \mathrm{x}_{base}$
    \item 복합 예시: $\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$ (여기서 $dx$의 $d$는 보존되고 $x$만 바뀔 수 있습니다.)
\end{itemize}

\subsection{3. 복잡한 환경 (Complex Environments)}
\begin{equation}
    x(t) = \sum_{n=-\infty}^{\infty} c_n e^{j n \omega_0 t}
\end{equation}

\begin{align}
    x_1 &= a + b \\
    x_2 &= c + d + \text{note: x is independent} \\
    f(x) &= \sqrt{x^2 + 1}
\end{align}

\subsection{4. 명령어 기호 변경 (Command Refactor)}
여기서는 \textbf{\alpha}를 \textbf{\beta}나 \textbf{\gamma}로 변경해 보세요.
\begin{itemize}
    \item 기본: $\alpha + \beta = 1$
    \item 첨자 포함: $\alpha_0, \alpha_1, \dots, \alpha_n$
    \item 유사 명령어 보호: $\phi$와 $\varphi$는 서로를 건드리지 않아야 합니다. $\alpha$와 $\vec{\alpha}$ 등.
\end{itemize}

\subsection{5. 행렬 및 중첩 구조 (Matrices and Nesting)}
\[
\begin{pmatrix}
x & y \\
z & x
\end{pmatrix}
\times
\begin{bmatrix}
x^2 \\
y^2
\end{bmatrix}
\]

중첩된 분수:
$ \frac{x}{1 + \frac{1}{x}} $

\subsection{6. 경계 조건 테스트 (Boundary Conditions)}
\begin{itemize}
    \item 다른 문자와 붙어있는 경우 (무시되어야 함): $xy + yx + ax + x$ (마지막 $x$만 바뀌어야 함)
    \item 괄호 및 중괄호: $(x), \{x\}, [x]$
    \item 수식 기호가 텍스트 모드 바깥에 있는 경우:
    이 문장 속의 x는 바뀌지 않아야 합니다. 오직 $x$만 바뀌어야 합니다.
\end{itemize}
